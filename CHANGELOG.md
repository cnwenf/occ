## 2.1.301 - 2026-08-15 (OCC-94)

- **OCC-94 — caught up with official Claude Code `2.1.232`** (npm `latest`/`next` = `2.1.232`; GitHub release `v2.1.232`; fresh official 2.1.231/2.1.232 linux-x64 ELFs downloaded and strings-diffed against the 2.1.231 baseline). Full 49-entry 2.1.232 changelog triage (4 ported / 19 staged with per-site rationale / 26 N/A trimmed-or-dormant surfaces) in `docs/upstream-version-gap-occ94.md`. A security-leaning upstream release: all 4 portable items are security/permission hardening, and all 4 LANDED byte-verified against the ELF.
  - **(A) GitLab token-family redaction.** The team-memory secret scanner now covers all 11 routable GitLab token families — `glpat-`, `gldt-` plus the new `glrt-`, `gloas-`, `glptt-`, `glagent-`, `glimt-`, `glsoat-`, `glcbt-`, `glft-`, `glffct-` — on the official shared body shape (`gl<Prefix>-[\w=-]{20,}` + optional 9-char lowercase rotation suffix; binary constant `X1e`, byte-identical). `ruleIdToLabel` special-cases the `CI`/`SCIM` acronym capitalization to match the official labels.
  - **(B) Nested-git-repo trust boundary.** Nested git repositories no longer inherit trust from a trusted parent directory — each repository now requires its own trust confirmation. A new uncached git-root probe (`findGitRootUncached`/`isGitRootForTrust`, port of the official `YEo`/`uXc`; symlinked `.git` rejected outright — a documented stricter subset of the official `nXc`) bounds the previously unbounded ancestor walk in both `computeTrustDialogAccepted` and `isPathTrusted`; same-repo children still inherit, non-git directories keep the unbounded walk, and a new `advisoryNoFsProbe` mode performs the walk with no filesystem probes and no boundary (port of the official `v8e` dual mode).
  - **(C) Bash `< file` input-redirect permission checks.** Bash input redirections (`< file`) are now permission-checked like their argument spellings: the AST redirect list is validated at `checkPathConstraints` (skip non-`<` ops and `< /dev/null`; every other target goes through the read-permission path), deny rules surface as `deny`, scope failures as `ask` with a Read-rule suggestion — byte-parity with the official `Dxr` loop and messages. Output-redirect behavior is untouched.
  - **(D) `sandbox.ripgrep` source-scope restriction.** `sandbox.ripgrep` is now honored only from managed (policy), `--settings` flag, and user settings, in that priority order (port of the official `rTt`); project/local settings can no longer point the sandbox's search binary at an arbitrary executable. Falls back to the bundled ripgrep. Security-positive.
  - **Tests:** 32 new targeted unit tests (input-redirect pass-through/ask/deny/`/dev/null`/heredoc/`<&`/output-redirect-unaffected/suggestion shape; all 11 GitLab families + rotation suffix + sub-20-char rejection + labels + redaction; nested-trust against REAL tmpdir `.git` dirs incl. symlinked-`.git` and advisory-probe cases; ripgrep source scope incl. project/local exclusion and priority order); full src suite **1930 pass / 0 fail / 4524 expect() / 206 files** (baseline entering: 1898/0/4480/202); curated e2e subset **56 pass / 194 expect()** (occ-versioning + commands-alignment + all five version-2.1.219-* + resume-interrupted-turn-221); build green (`dist/cli.js` 28.89 MB); Biome 0 findings on the 9 touched/new files; live smokes: `-p` model round trip + tmux REPL boot / model query / `/status` / clean `/exit`. Security review: no backdoor, no CRITICAL/HIGH — the two hardening ports (ripgrep scope, nested-repo trust boundary) verified complete; LOW-only notes (the symlinked-`.git` divergence is intentional/documented/tested/contained; the input-redirect port rides OCC's dormant AST path while the live legacy path stays stricter with a fail-closed `<` guard).

- **Fix: `occ` failed to launch after `npm i -g @cnwenf/occ` on glibc hosts** (OCC-6). The Node launcher shim (`bin/occ.cjs`) died with `occ: failed to launch bun: spawn .../@oven/bun-linux-x64-musl/bin/bun ENOENT`. Verified in clean `node:20` (glibc), `--ignore-scripts`, and `node:20-alpine` (musl) containers. Added `test/launcher.test.ts` (9 tests) pinning the libc filtering and probe behavior.
